# 이미 겪은 실패 (새 캐릭터 시작 전에 읽기)

냐블로 주인공을 네 번 다시 만들고(v1~v4, 데스나이트) 동작·무기를 여러 번 고치며 겪은 것이다. 괄호는 냐블로 제작 기록의 절 번호다.

## 설정화·생성

| 증상 | 원인 | 대응 |
| --- | --- | --- |
| 고품질로 만들었는데 "디아블로 4처럼 안 됐다" | 입력 설정화가 머리 크고 매끈한 스타일. Tripo는 입력을 충실히 옮김 (4-11) | 설정화부터 목표 스타일 참고를 넣어 다시 그림 |
| 칼을 손으로 안 잡은 것처럼 보임 | 펼친 손, Tripo 뼈대에 손가락 뼈 없음 (4-18) | 주먹 구멍(4-19) 또는 08 방식 B1 손 교체·고정 파지(4-39 검증); 잡기/놓기 동작은 별도 |
| 방향마다 부위 크기·목 길이가 다름 | 방향마다 따로 그림 | 정면을 먼저 그리고 그것을 기준으로 나머지 방향 |
| 금속·천이 얼룩덜룩 | codex 그림의 때 자국 | 얼룩 제거 재작화 + 배경 #d0d0d0 |

| codex 결과가 작업 폴더에 없음 | 샌드박스 복사 실패 | 세션 `generated_images/<session>`에서 회수(`run_codex.sh`) |
| 게임에서 찰흙처럼 보임 | Tripo 저폴리 출력(P1, smart_low_poly)의 평평한 노멀·AO 없음·수천 UV 조각 (4-7) | detailed 생성 + 면 줄이기 + 노멀 다시 굽기, 필요하면 UV 재작업 |

| 면 줄이기·텍스처 작업 실패(환불) | 부위 분리 결과에 면 줄이기, 리토폴로지 결과에 `model texture` (4-13) | 면 줄이기는 원본 생성 task에 |

## Blender 처리

| 증상 | 원인 | 대응 |
| --- | --- | --- |
| 손·머리·트위스트 뼈 11개 사라짐 | FBX 가져오기 `ignore_leaf_bones=True` (3-3) | 끔 |
| 망토·팔이 찢어짐 | 다른 형태의 옛 뼈대에 가중치 옮김(형태 차이 4.6%) (4-8) | 게임 메시와 같은 모델을 리깅 |
| 가중치 옮긴 뒤 조각이 늘어남 | 동작 중인 자세에서 옮김 | 기본 자세에서 |
| 천 시뮬레이션이 560조각으로 찢어짐 | UV 이음매로 나뉜 정점 (4-12) | 정점을 합친 시뮬레이션용 복사본 |
| 털·천 금속 반사, 갑옷 젖은 플라스틱, 코등이 밀랍 | Tripo 금속성·거칠기 맵이 흐린 덩어리, 칠해진 빛 (4-13, 4-20) | 부위별 ORM 보정 + `fix_textures.py` |
| 흑철이 은백색, 뼈색 테두리가 밝은 금속 | `fix_textures.py` 기본 F0 (4-24) | `--steel-f0 keep --steel-chroma 1 --gold-f0 keep` |
| 스캔 재질을 덧씌웠더니 더 지저분 | 잡음·흰 이음매·과한 반사 (4-13) | Tripo 텍스처 기반 보정만 |
| 붉은 천이 털로 분류됨 | byte 이미지 `.pixels`(이미 sRGB)를 한 번 더 변환 (4-11) | 변환하지 않음 |
| 텍스처 파일이 조용히 안 생김 | Blender `Image.save()`·`process_props.py --out`에 상대 경로 (4-23, 4-24) | 절대 경로 |
| 게임 속 캐릭터가 작아짐 | 털 겹이 키 계산에 들어감 (4-14) | `_Fur`·`Sim` 슬롯 제외 |
| UV 조각을 이웃에 붙였더니 톱니 모양, 사용률 27% | 부스러기 합치기 방식 (4-21) | 부위 기준 조각 + tree-cotree 절단(`reuv_bake.py`) |

## 동작

| 증상 | 원인 | 대응 |
| --- | --- | --- |
| 이동 중 순간이동 | "제자리" 동작도 Hip이 전진 후 반복 때 되돌아감 (4-1) | run/walk의 Hip 전진 제거, 뺀 속도로 재생 배속 |
| 전봇대처럼 서서 팔만 휘두름 | 리타깃이 엉덩이 수평 이동을 버림 (4-27) | 공격 구간 `--rezero` + 캡슐 이동(lunges) |
| 역동적인 느낌이 없음, 칠 때마다 끊김 | 동작을 잘라서 바꿈(전환 튐 14~35%), 몸이 꼿꼿하고 보폭이 작음 (4-29) | `NyabloAnimInstance` 섞기 + `--attack-body` |
| 블렌더 IK로 다리를 맞췄더니 발목·무릎이 틀어짐 | 짧은 넓적다리·종아리 뼈 + 비틀림 뼈 구조 (4-29) | 두 관절 직접 계산 |
| 루트 모션을 켜자 주인공이 맵 밖으로 | 원인 미상(Root 뼈 yaw −90° 등, 강베기 한 번에 63m) (4-27) | 루트 모션을 쓰지 않음 |
| 역경직이 칼이 닿기 전 자세에서 멈춤 | 적중 프레임을 손 속도 최대로 잡음 (4-29) | 칼끝이 가슴 높이를 지나는 프레임(`tip_path.py`) |
| 섞는 동안 몸이 뒤로 끌림 | 페이드아웃 공격이 다음 구간(이동 0으로 재시작)까지 재생, 늘린 보폭이 구간 뒤 되돌아감 (4-29) | `MaxTime` = 구간 끝 + 0.1초, 늘린 보폭 유지 |
| 허공을 휘젓는 느낌 | 베는 구간이 1~2프레임, 베기 효과가 칼 경로와 무관 (4-28) | 검 궤적을 칼에 붙이고, 준비 느리게·내려치기 빠르게 |
| 준비·내려치기를 고쳐도 흐느적거림, 타격감 없음 | 모션 캡처의 부드러운 감속: 적중 뒤에도 최고 속도의 60~90%로 흘러가고 멈추는 데 0.2~0.4초, 적중 뒤 구간에 배속 조절 없음 (2026-09-29 측정) | 07 "타격감": `impact_profile.py`로 재고 적중 뒤 급정지·버팀·회복을 나눔 (효과는 검증 전, backlog H6) |
| 동작은 자연스러운데 "맛이 없다" | 베기 배속이 준비보다 느림(막대 느낌을 피하려고 낮춤): 모았다가 터지는 대비 없음 (2026-10-01) | 07 "무기 성격에 맞는 리듬". 막대 판정은 속도비로, 쾌검은 전체를 빠르게 + 비틀기 |
| 한손검이 "둔기로 치는 것 같다" | 꼭대기 모으기·끝 버팀·느린 준비·크게 낮추기 = 무거운 무기 신호 (2026-10-01) | 모두 빼고 적중 뒤 이어가기를 베기 속도로, 회복 빠르게 |
