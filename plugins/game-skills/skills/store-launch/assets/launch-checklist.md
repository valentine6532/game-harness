# 앱 출시 체크리스트 (결제 + 광고 + 통계)

인앱결제, 보상형 광고, 이용 통계를 붙인 모바일 앱을 App Store와 Google Play에 내기 위해 필요한 일 전체 목록입니다.
상태는 **【앱 이름】** 기준이며 【날짜】에 마지막으로 갱신했습니다.
무엇을 왜 그렇게 정했고 어떤 파일을 바꿨는지는 [launch-log.md](launch-log.md)에 있습니다.

| 표시 | 뜻 |
|---|---|
| ✅ | 완료. 저장소나 검증 기록으로 확인됨 |
| ⬜ | 미완료. 해야 함 |
| ❓ | 확인 필요. 스토어 콘솔 안의 항목이라 저장소에서는 알 수 없음. 본인이 콘솔에서 확인 후 ✅ 또는 ⬜로 바꾸기 |
| ➖ | 해당 없음. 이유를 메모에 적음 |

담당 칸의 **본인**은 계정·콘솔·법적 신고처럼 직접 해야 하는 일, **코드**는 프로젝트 안에서 고치는 일입니다.
스토어 정책은 자주 바뀝니다. 크기, 인원, 기간 같은 수치는 제출 전에 콘솔 화면과 공식 문서로 다시 확인하세요.
