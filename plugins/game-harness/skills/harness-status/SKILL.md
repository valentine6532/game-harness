# 하네스 상태 확인

## 도구 위치

관리 도구는 `${CLAUDE_PLUGIN_ROOT}/scripts/harness.py`다. 이 경로에 `${...}`가 글자 그대로 남아 있으면, 이 `SKILL.md`가 있는 폴더에서 `../../scripts/harness.py`를 찾아 쓴다.

## 절차

1. 게임 프로젝트의 최상위 폴더에서 실행한다.

   ```
   python "<도구 경로>" status --project .
   ```

2. 출력을 사용자에게 정리해 알린다.
   - 적용된 버전과 고른 기능
   - 플러그인 버전과의 차이
   - 손으로 고쳐진 파일, 없어진 파일, 기록에 없는 파일
   - 경고

3. 하네스가 적용되어 있지 않다고 나오면 그렇게 알리고, 적용하려면 `harness-apply`를 쓰면 된다고 안내한다.

4. 버전이 다르거나 파일 차이가 있으면, 출력된 차이(버전, 변경 내용, 추가·삭제·변경되는 파일, 덮어써질 수정)를 사용자에게 보여주고 업데이트할지 묻는다. 사용자가 진행하겠다고 답하면 `harness-update`의 절차를 따른다. 답하기 전에는 아무것도 바꾸지 않는다.

5. "원본 저장소의 최신 태그"가 플러그인 버전보다 높다고 나오면, 플러그인을 먼저 갱신해야 새 버전을 받을 수 있다고 알린다. Claude Code는 `/reload-plugins`나 새 세션, Codex는 앱 재시작이다.

## 지킬 것

- 이 스킬은 읽기만 한다. `status`는 파일을 바꾸지 않는다.
- 손으로 고쳐진 파일을 발견해도 되돌리거나 고치지 않는다. 사용자에게 알리고, 필요한 내용은 `.game-harness/overrides/`로 옮기거나 공통 하네스에 반영(`harness-promote`)하도록 안내한다.
