# 시험 뒤 정리

시험과 필요한 검토가 끝나면 그 실행을 위해 만든 임시 파일을 지운다.

## 지우는 것

- 일회용 시험 프로젝트, 임시 스크립트
- 캡처, 영상
- 더 필요 없는 자세한 기록

## 남기는 것

- 간단한 검증 요약
- 다시 쓸 시험 코드, 시험용 자료, 비교 기준
- 사용자가 요청한 결과물
- 아직 해결되지 않은 실패를 조사하는 데 필요한 자료

## 지킬 것

- 지우기 전에 정확한 경로가 의도한 프로젝트 출력 폴더 안에 있는지 확인한다.
- 실행 중인 에디터나 시험 작업이 쓰고 있는 파일은 지우지 않는다.
- 이 정리를 위해 백업을 만들지 않는다.
- 지우지 못한 파일이 있으면 남은 파일과 이유를 보고한다.
