# Unity 기능

Unity 프로젝트에서 작업할 때 공통 절차에 더해 따르는 지침이다.

| 상황 | 읽을 파일 |
| --- | --- |
| 에디터 작업, 백그라운드 검사를 실행할 때 | `editor-jobs.md` |

## 공식 스킬

- Unity 공식 스킬(`Unity-Technologies/skills`)이 설치되어 있으면 해당하는 스킬을 쓴다.
- 공식 스킬의 구현 방식이 프로젝트의 기존 코드나 관례와 다르면 공식 스킬을 따른다. 기존 구현이 있다는 것은 공식 방식을 거부할 이유가 아니다.
- 옮겨 가는 작업은 요청받은 범위 안에서만 한다. 영향받는 런타임 참조와 생성 도구를 함께 고친다.
- 검증은 예외다. 공식 스킬이 사용자에게 확인을 맡기라고 해도, 프로젝트의 검증 도구로 에디터 검사와 실제 화면 검토를 직접 한다.

## 화면 확인

화면이 바뀌는 작업은 Unity에서 확인한 뒤에 "에디터나 시뮬레이터에서 보인다"고 보고한다.

## 빌드

기기용 빌드와 패키징(APK 등)을 요청 없이 할 수 있는지는 `project.yaml`의 "요청 없이는 하지 않는 작업"을 따른다. 적혀 있지 않으면 에디터 검사를 기본으로 하고, 빌드는 사용자에게 먼저 확인한다.
