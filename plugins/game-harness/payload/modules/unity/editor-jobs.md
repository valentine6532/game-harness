# 에디터 작업과 백그라운드 실행

## 플레이 중에는 끼어들지 않는다

- 사용자가 에디터에서 게임을 실행 중일 수 있다. 에디터 작업은 플레이 모드가 끝날 때까지 기다리도록 대기열에 넣는다. 플레이를 중단시키지 않는다.
- 생성된 자원을 지우고 다시 만드는 작업은 플레이 모드와 검증 작업이 모두 멈춘 상태에서 한다.

## 창을 띄우지 않는다 (Windows)

- 사용자가 플레이하는 동안 PowerShell이나 cmd 창이 보이면 안 된다.
- 백그라운드 검사는 창이 없는 실행 방식으로 시작한다. Node는 `child_process.spawn(..., { windowsHide: true, shell: false })`, Python은 `pythonw.exe`를 쓴다.
- Python에서 하위 프로세스를 시작할 때는 `CREATE_NO_WINDOW`를 지정한다.
- 보이는 터미널을 부모로 해서 숨긴 프로세스를 띄우지 않는다. 부모 창이 보인다.

## 시간 초과와 재시도

- 에디터에 보낸 요청이 시간 초과되거나 중단되면, 다시 보내기 전에 대기 중이거나 실행 중인 작업을 확인한다. 요청은 여전히 진행 중일 수 있다.
- 같은 작업을 겹쳐 보내지 않는다.
