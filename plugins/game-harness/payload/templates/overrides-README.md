# 이 게임만의 예외

이 폴더는 게임 프로젝트가 주인이다. 하네스 업데이트로 바뀌지 않는다.

공통 절차(`.game-harness/harness/`)와 다르게 해야 하는 것, 이 게임에만 필요한 검증을 여기에 마크다운 파일로 적는다. 여기 적힌 내용은 공통 절차보다 우선한다.

## 적는 방법

- 주제별로 파일을 나눈다. 예: `atlas.md`, `stage-checks.md`.
- 무엇을 다르게 하는지와 그 이유를 함께 적는다.
- 공통 하네스의 문제를 당장 피하려고 적은 임시 규칙은 파일 맨 위에 "임시"라고 표시하고, 어떤 문제 때문인지 적는다. 공통 하네스에 반영된 뒤 지운다.
