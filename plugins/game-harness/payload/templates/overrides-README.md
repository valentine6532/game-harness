# 이 게임만의 예외

이 폴더는 게임 프로젝트가 주인이다. 하네스 업데이트로 바뀌지 않는다.

공통 절차(`.game-harness/harness/`)와 다르게 해야 하는 것, 이 게임에만 필요한 검증을 여기에 마크다운 파일로 적는다. 여기 적힌 내용은 공통 절차보다 우선한다.

## 적는 방법

- 주제별로 파일을 나눈다. 예: `atlas.md`, `stage-checks.md`.
- 무엇을 다르게 하는지와 그 이유를 함께 적는다.
- 공통 하네스의 문제를 당장 피하려고 적은 임시 규칙은 파일 맨 위에 "임시"라고 표시하고, 어떤 문제 때문인지 적는다. 공통 하네스에 반영된 뒤 지운다.

## 전역 제작 스킬과 에이전트

- `skills/<스킬 이름>/override.md`: 해당 스킬에만 적용할 변경·추가 지침.
- `agents/<에이전트 이름>/override.md`: 해당 에이전트에만 적용할 변경·추가 지침.
- 실행한 스킬·에이전트의 시작 절차가 파일을 확인하고, 없으면 빈 템플릿만 만든다. 사용하지 않은 항목의 파일은 만들지 않는다.
- 기본 지침 전체를 복사하지 않는다. 명시한 항목만 바꾸고, 나머지는 전역 기본 지침을 따른다. 사용자의 직접 지시가 우선한다.
- 하네스의 전역 업데이트는 이 폴더를 변경하지 않는다. 사용 중인 오버라이드의 기본 지침이 바뀌면 시작 절차에서 검토 안내가 나온다.
- Markdown은 지침만 바꾼다. 전역 실행 코드는 교체하지 않는다. 도구 경로·환경 설정은 필요할 때 해당 스킬의 안내에 따라 로컬에 둔다.
