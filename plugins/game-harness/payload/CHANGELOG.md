# 게임 하네스 변경 내역

버전마다 `## 버전 - 날짜` 제목으로 항목을 만든다. 최신 버전을 맨 위에 둔다. 업데이트할 때 이 제목을 기준으로 두 버전 사이의 변경 내용을 보여주므로 제목 형식을 지킨다.

## 0.1.1 - 2026-10-05

관리 도구만 바뀌었다. 게임에 복사되는 절차 문서는 0.1.0과 같다.

- 상태 확인을 하면 GitHub 원본 저장소에 올라온 최신 버전을 확인한다. 설치된 플러그인보다 새 버전이 있으면 플러그인을 먼저 갱신하라고 알린다.
- 원본 저장소에서 직접 실행할 때의 경고를 고쳤다. 플러그인과 무관한 커밋을 한 뒤에도 "태그가 없다"고 경고하던 것을, 태그 이후 플러그인 내용이 실제로 바뀌었을 때만 경고하게 했다.

## 0.1.0 - 2026-10-04

첫 버전. `dino-excape`에서 쓰던 작업 규칙 중 다른 게임에도 통하는 것을 옮겼다.

- 공통: 작업 순서(계획·실행·검증·보고), 검증 범위와 보고 규칙, 시험 뒤 정리 규칙.
- unity 기능: 공식 스킬 우선, 플레이 중 에디터 작업 대기, 창 없는 백그라운드 실행, 시간 초과 뒤 재시도 전 확인.
