# 게임 하네스 변경 내역

버전마다 `## 버전 - 날짜` 제목으로 항목을 만든다. 최신 버전을 맨 위에 둔다. 업데이트할 때 이 제목을 기준으로 두 버전 사이의 변경 내용을 보여주므로 제목 형식을 지킨다.

## 0.1.1 - 2026-10-05

- 작업 인계 기록을 추가했다(`core/handoff.md`). 작업마다 `.game-harness/work/now/`에 파일 하나를 두어, 여러 세션이 서로 무엇을 하고 있는지 알고 멈춘 작업을 이어받는다. 끝난 작업은 `work/done/<연-월>/<일>/`로 옮긴다. 적용하거나 업데이트하면 `work/` 폴더가 없을 때 자동으로 만들어진다.
- 작업 인계 규칙을 훅으로 강제한다. 파일을 고치기 직전에 확인해서, 자신의 작업 파일이 없거나 다른 작업이 잡은 곳이면 수정을 거부한다. 그래서 파일을 고치는 작업은 크기와 상관없이 작업 파일이 필요하다. 훅은 플러그인에 들어 있으며, 하네스가 적용되지 않은 프로젝트에서는 아무것도 하지 않는다.
- 한 번에 한 세션만 쓸 수 있는 것(엔진 에디터, 검증 실행)을 차례대로 쓰게 하는 `core/tools/with_lock.py`를 추가했다. 에디터를 쓰는 검증 명령은 이것으로 감싸 실행하는 것이 기본이다.
- `AGENTS.md`의 하네스 구역에, 작업 시작 전 `work/now/`를 읽고 작업 파일을 만들라는 안내를 넣었다.
- 게임 쪽에서 할 일: `work/.gitignore`가 새로 생긴다. 함께 커밋한다.
- 상태 확인을 하면 GitHub 원본 저장소에 올라온 최신 버전을 확인한다. 설치된 플러그인보다 새 버전이 있으면 플러그인을 먼저 갱신하라고 알린다.
- 원본 저장소에서 직접 실행할 때의 경고를 고쳤다. 플러그인과 무관한 커밋을 한 뒤에도 "태그가 없다"고 경고하던 것을, 태그 이후 플러그인 내용이 실제로 바뀌었을 때만 경고하게 했다.

## 0.1.0 - 2026-10-04

첫 버전. `dino-excape`에서 쓰던 작업 규칙 중 다른 게임에도 통하는 것을 옮겼다.

- 공통: 작업 순서(계획·실행·검증·보고), 검증 범위와 보고 규칙, 시험 뒤 정리 규칙.
- unity 기능: 공식 스킬 우선, 플레이 중 에디터 작업 대기, 창 없는 백그라운드 실행, 시간 초과 뒤 재시도 전 확인.
