# 1. 설정화

Tripo는 입력 이미지를 충실히 옮긴다. 품질의 상한은 설정화가 정한다. 머리가 크고 매끈한 스타일라이즈드 그림을 넣으면 그런 모델이 나온다(냐블로 4-11). 원하는 화면 기준(예: 디아블로 4 캡처)을 스타일 참고로 같이 넣는다.

## 순서

1. **디자인 원안**: 정체성 참고(기존 캐릭터) + 스타일 참고를 넣어 생성한다. 비스듬한 각도와 명암이 있어도 된다. 3D 입력으로는 쓰지 않는다. 여러 안을 만들어 사용자가 고르게 한다.
2. **모델 시트(정면)**: 원안을 3D 입력용으로 다시 그린다. 예시 프롬프트는 `reference_impl/deathknight/prompts/01_front_sheet.txt`.
   - 정면 정투영, 좌우 대칭, A포즈(팔을 몸에서 약 35° 벌림, 팔과 몸 사이 빈 공간).
   - 칼을 쥘 캐릭터는 **먼저 쥐는 방식을 정한다**(08_weapon.md "쥐는 방식 고르기"). A(쥔 주먹): **주먹에 칼자루 구멍이 앞뒤로 뚫린** 빈손. 손가락 뼈 없이 펼친 손으로 모델링하면 칼을 쥘 수 없다(Tripo 뼈대에는 손가락 뼈가 없다). B(손가락 뼈 심기, 미검증): 무기 없이 살짝 편 손, 손가락 사이에 틈이 보이게.
   - 무기 없음. 무기는 따로 만든다(손과 무기가 붙어서 생성되는 문제를 원천 차단).
   - 명암 없는 평면 조명(albedo처럼): 그림자·AO·하이라이트·림라이트·비네트·발광 번짐 없음.
   - 배경 단색 #d0d0d0, 전신이 여백을 두고 화면 안에.
   - 망토·앞자락 같은 천은 몸에서 빼고 따로 만든다(탈착·천 시뮬레이션 때문). 몸 그림에서 천을 모두 지운다.
   - **방향 검사**: 정면 그림이 나오면 바로 [front_check.md](front_check.md)대로 3/4 틀어짐을 확인하고, 불합격이면 최대 2번 다시 그린다. 4방향·부위 그림도 그림마다 같은 검사를 한다.
3. **4방향(정면·왼쪽·뒤·오른쪽)**: 정면을 기준 이미지로 넣고 나머지 방향을 그린다. "왼쪽 = 캐릭터의 왼쪽 옆면(이미지 왼쪽을 봄)"처럼 방향을 명시한다. 꼬리·천 위치가 방향마다 달라지면 정면에 맞춰 다시 그린다.
4. **얼룩 제거**: codex 그림은 금속·천에 얼룩덜룩한 때가 깔린다. 같은 이미지를 한 번 더 넣어 "형태는 그대로, 표면의 얼룩·때·반점만 지우고 고른 색 + 가장자리 마모만"으로 다시 그린다(`prompts/05_clean_surface.txt`). 그다음 `scripts/bg_fill.py`로 배경을 정확한 #d0d0d0으로 칠한다.
   - 부위 설정화는 생성 프롬프트에 깨끗한 표면 조건을 넣고 얼룩 제거 재작화를 하지 않았다. 다시 그리면 방향 간 정렬이 틀어진다.
5. **부위별 설정화**(부위 생성을 할 때): 4방향 몸 그림에서 부위를 잘라(`src.png`) 고해상도로 다시 그린다. 머리·팔·몸통·하체 각 4방향이다. 예시: `prompts/02_part_head_front.txt`, `03_part_head_side_matched.txt`, `04_part_arm_front.txt`.
   - 자르는 곳은 갑옷 경계다: 머리 = 목깃 아래 평평한 절단, 팔 = 어깨 갑옷 안쪽 위팔(어깨 갑옷은 몸통에 포함), 하체 = 허리띠 아래.
   - 방향마다 크기가 달라지는 문제가 있다. **정면을 먼저 그리고**, 나머지 방향은 정면 결과를 기준 이미지로 넣어 "같은 이미지 크기, 귀 끝·눈·턱·목 절단 높이가 같은 위치"로 그리게 한다.
   - 팔은 한쪽만 수직으로 늘어뜨려 그리고 조립 때 좌우로 뒤집는다. 주먹 구멍은 앞뒤로 뚫려야 한다(옆모습에서 구멍이 보이면 고친다).
   - 사슬 치마처럼 두 다리에 걸친 부위는 한쪽 다리 뒤집기가 안 된다. 하체를 한 덩어리(허리 아래 + 꼬리)로 그린다.
   - 이미지 가장자리에서 잘리면 여백을 두게 다시 그린다.
6. **무기·망토 단독 그림**: 무기는 두세 안을 그려 고르게 한다. 망토는 몸에 맞추지 않은 단독 평면 그림(바깥면/안면)을 만든다. 이 그림이 망토 텍스처가 된다(09_cloth_fur.md).

## 실행

```bash
bash $SKILL/scripts/run_codex.sh <작업 폴더> <tag> <prompt.txt> <out.png> <참고 이미지...>
python $SKILL/scripts/bg_fill.py <in.png> <out.png>      # 배경 #d0d0d0
```

- codex가 결과를 작업 폴더로 복사하지 못하는 경우가 있다(샌드박스 오류). `run_codex.sh`가 세션 폴더에서 가져온다.
- codex가 그림 없이 질문으로 끝나는 경우가 있다. 프롬프트를 더 단정적으로 바꿔 다시 돌린다.
- 병렬로 여러 장을 돌릴 수 있다(최대 5개).

## 합격 기준

- 모든 방향 그림이 [front_check.md](front_check.md) 검사를 통과했다(경미 판정은 기록과 함께 허용).
- 방향 간 디자인·꼬리·장식 위치가 일치한다. 앞 장식이 뒤에 반복되지 않는다.
- 평면 조명, 배경 #d0d0d0, 전신(또는 부위)이 여백을 두고 들어간다.
- (쥐는 방식 A) 주먹 구멍이 정면에서 보인다. (B) 손가락 다섯 개가 떨어져 보인다.
- 사용자가 시안을 보고 3D 진행을 승인했다(크레딧이 드는 다음 단계 전 확인 지점).
