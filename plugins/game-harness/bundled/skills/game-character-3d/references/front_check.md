# 설정화 방향 검사 (정면·옆·뒤)

World of Oldcraft 키트의 `character-sheet-pipeline` V3 검사(Stage 4.5)를 이 스킬에 맞게 옮긴 것이다. 이미지 모델은 "정면"이라고 해도 3/4 각도로 슬쩍 돌아간 그림을 자주 낸다. 틀어진 그림이 Tripo에 들어가면 방향 간 크기·목 길이가 어긋나고 부위가 안 맞는다(pitfalls "방향마다 부위 크기·목 길이가 다름"). **크레딧을 쓰기 전에 그림 단계에서 거른다.**

검사는 에이전트가 이미지를 직접 열어 본다. 별도 서비스는 없다.

## 언제

- 정면 모델 시트(01 순서 2) 직후. 여기가 틀리면 뒤가 모두 틀린다.
- 4방향(01 순서 3)의 옆·뒤 그림마다. 기대 방향만 바꿔 같은 방식으로 본다.
- 부위별 설정화(01 순서 5)의 각 방향 그림마다.

## 정면 검사 항목

1. **몸 축이 정면**: 좌우 폭이 같다. 몸이 수평으로 돌아가 있지 않다.
2. **3/4 아님**: 정면과 옆 사이로 돌아간 기색이 없다. 가장 흔한 틀어짐이라 엄격하게 본다.
3. **비틀림 없음**: 골반·어깨가 틀어지지 않았고, 머리가 가슴과 다른 쪽을 보지 않는다.
4. **카메라 눈높이**: 올려다보거나 내려다보는 원근이 없다.
5. **등이 안 보임**: 등 표면이 조금이라도 보이면 정면이 아니다.
6. **구도**: 배경 #d0d0d0, 전신(또는 부위)이 잘리지 않고 여백을 두고 들어간다.

옆 그림은 1·2·5 대신 "정확히 90°, 정면과 옆 사이도 옆과 뒤 사이도 아님, 정면과 같은 A포즈"를 본다. 뒤 그림은 "등이 정면으로, 얼굴이 조금도 안 보임"을 본다.

## 판정

| 판정 | 조건 | 처리 |
| --- | --- | --- |
| 통과 | 모두 맞음 | 다음 단계 |
| 경미 | 4·6 중 하나만 살짝 어긋남, 3D 입력으로는 쓸 만함 | 경고를 기록하고 진행 |
| 불합격 | 1·2·3·5 중 하나라도 분명히 틀림 | 다시 그림 |

## 다시 그리기 (최대 2번)

1. **1번째**: 같은 프롬프트 맨 앞에 틀린 이유를 구체적으로 넣는다. 예: "이전 그림은 카메라 오른쪽으로 약 25° 돌아갔다. 이번에는 반드시 정면 정투영이다." 3/4·영웅 각도 금지 문구를 강하게 한다.
2. **2번째**: 기준 이미지(이미 통과한 정면 그림)를 함께 넣고 "이 그림과 같은 각도"로 다시 그리게 한다. 정면 시트 자체가 틀린 경우에는 통과한 정면이 아직 없으므로, 디자인 원안(01 순서 1)을 디자인 기준으로만 넣고 각도는 프롬프트로 한 번 더 강하게 지시한다.
3. **그래도 불합격**: 멈추고 세 장을 사용자에게 보여 준다. 하나를 고를지, 지시를 바꿔 다시 그릴지, 그 부위를 건너뛸지 묻는다.

판정(통과/경미/불합격, 이유, 몇 번째 시도)은 `concepts/front_check.json`에 남긴다.
