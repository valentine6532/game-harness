# Unity 2D bone animation: official workflow and samples

Use this reference when the user asks to learn the workflow, reproduce an official example, or build a bone-driven 2D character. The linked Korean Unity pages describe 2D Animation **13.0** (Unity **6000.3**). First identify the project's Editor version and resolved `com.unity.2d.animation` version, then use that version's package documentation and sample assets for exact labels and paths. This reference summarizes decisions and checkpoints; the official pages remain the source for full UI details.

## Pick an official sample that matches the art

In **Window > Package Manager**, select **2D Animation**, expand **Samples**, and use **Import**. Samples are placed in `Assets/Samples/2D Animation/[package version]/Samples/`. The following 13.0 examples use PSD Importer, so check that package before importing them. Prefer importing into a learning or scratch project when the user only wants to study an example; use the active project when requested or when integration is the task. [Unity sample catalog](https://docs.unity3d.com/kr/Packages/com.unity.2d.animation@13.0/manual/Examples.html)

| Goal | Sample to open and inspect |
| --- | --- |
| See one sprite bend under a simple bone chain | [Simple](https://docs.unity3d.com/kr/Packages/com.unity.2d.animation@13.0/manual/ex-simple.html): open `_Simple` scene and `1 Simple/Sprites/Boris.psd` in Skinning Editor. |
| See a branched skeleton on one sprite | [Single Skinned Sprite](https://docs.unity3d.com/kr/Packages/com.unity.2d.animation@13.0/manual/ex-single-skinned-sprite.html): open `_Single Skinned Sprite` scene and `2 Single Skinned Sprite/Sprites/Plunkah.psd`. |
| See a layered, multi-sprite humanoid | [Character](https://docs.unity3d.com/kr/Packages/com.unity.2d.animation@13.0/manual/ex-psd-importer.html): open `_Character` scene and `3 Character/Sprites/Fei.psb`. |

In each sample, trace the source art -> generated sprites and prefab -> bone hierarchy -> geometry and weights in Skinning Editor -> Sprite Skin on the scene object -> Animation clips and Animator Controller. Scrub the clip and inspect a bent joint. To reconstruct rather than merely play a sample, follow its own page; `Simple` uses both a root Animator and a Boris Animator. Search by asset name in the imported sample when a documentation path disagrees with the actual sample folder (the 13.0 Character page names both `3 Character` and `4 Character`).

## Reproduce the official production path

1. **Prepare art and choose import mode.** For a layered character, keep each moving part on a layer, include hidden overlap at joints, and preserve the source file. The official [artwork import guide](https://docs.unity3d.com/kr/Packages/com.unity.2d.animation@13.0/manual/PreparingArtwork.html) uses a `.psb` imported with PSD Importer. Its multi-part example sets Texture Type to **Sprite (2D and UI)**, Sprite Mode to **Multiple**, **Mosaic** and **Character Rig** on, then applies the import settings. The importer generates an actor prefab from the layers. Separate PNG sprites can also be rigged, but do not assume this PSD-specific import path applies to them.
2. **Create the rig in Skinning Editor.** Select the artwork, open **Sprite Editor > Skinning Editor**, and use **Create Bone** to define the smallest useful hierarchy. Generate a mesh with **Auto Geometry**, then inspect the shape around joints and correct it with geometry tools where needed. Use **Auto Weights** to bind vertices, remove irrelevant influences with **Bone Influence/Sprite Influence**, and refine bending with **Weight Slider/Weight Brush**. Use **Preview Pose** at several extreme angles; it is a temporary test pose, while **Edit Bone** changes the bind pose. Follow the [official rigging workflow](https://docs.unity3d.com/kr/Packages/com.unity.2d.animation@13.0/manual/CharacterRig.html) and [tool reference](https://docs.unity3d.com/kr/Packages/com.unity.2d.animation@13.0/manual/SkinEdToolsShortcuts.html).
3. **Connect the rig in the scene.** Add the generated actor prefab to a scene and inspect **Sprite Skin** on deforming sprites. The component maps scene bone Transforms to the rigged sprite and needs the correct Root Bone and bone entries. If binding does not happen, compare names and hierarchy; **Auto Rebind** also relies on matching them. Use **Create Bones** when working with a manually assembled single sprite whose Root Bone is still empty. See the [Sprite Skin guide](https://docs.unity3d.com/kr/Packages/com.unity.2d.animation@13.0/manual/SpriteSkin.html).
4. **Animate and check.** With the rigged actor in the scene, use Unity's **Animation** window to key the bone Transforms into clips, then assign and transition clips through an **Animator Controller**. Check the resulting Sprite Skin deformation in Play mode as well as while scrubbing; inspect seams, stretching, part order, and the intended camera scale. The [official actor-animation guide](https://docs.unity3d.com/kr/Packages/com.unity.2d.animation@13.0/manual/Animating-actor.html) covers this handoff from rigging to the animation timeline.

If the user supplied a single flattened image of a detailed multi-part character, determine whether it can deform cleanly before promising a full-body rig. Layer separation or repainting hidden joint areas may be needed. For faces, costumes, or large silhouette changes, consider the package's Sprite Swap examples instead of stretching one drawing through every pose.
