# 점검: 프로젝트가 지금 어디까지 되어 있나

"출시 가능한가"에 답하기 위해 저장소와 빌드에서 확인할 것들이다. 본 것만 사실로 쓰고, 볼 수 없는 것은 "확인 필요"로 남긴다.

## 1. 먼저 훑을 것

| 볼 것 | Unity 기준 위치 | 알 수 있는 것 |
|---|---|---|
| 들어간 SDK | `Packages/manifest.json` | 결제, 광고, 통계, 그 밖의 외부 서비스 |
| 앱 식별 정보 | `ProjectSettings/ProjectSettings.asset` | 제품명, 번들 ID, 버전, 빌드 번호, 대상 기기(iPhone/iPad), 최소 OS |
| 커밋 안 된 변경 | `git status` | 빌드에 아직 안 들어간 작업. 남의 작업이 섞여 있는지 |
| 기존 문서 | 저장소의 `*.md`, `docs/` | 이전에 한 설정, 이미 끝난 콘솔 작업의 기록 |
| 빌드와 업로드 기록 | 빌드 폴더, CI 설정, 검증 요약 | TestFlight나 내부 테스트까지 갔는지 |

기존 문서에 "소유자가 콘솔에서 무엇을 했다"는 기록이 있으면 완료로 볼 수 있지만, 날짜와 함께 "문서 기준"이라고 적는다.

## 2. 출시를 막는 흔한 빈틈

저장소에서 직접 찾을 수 있는 것들이다. 각각 근거가 되는 파일과 줄을 적는다.

- **테스트 스위치가 켜져 있음**: 테스트 광고, 테스트 결제, 개발용 치트. 설정 자산과 그것을 강제하는 검사 코드를 함께 찾는다. 스위치만 끄면 검사가 실패하는 경우가 있다.
- **빈 ID**: 플랫폼별 광고 단위 ID, 상품 ID. 한 플랫폼만 채워져 있는 일이 많다.
- **앱 안에 방침 링크 없음**: 코드에서 외부 주소 열기(`OpenURL`, `http`)를 검색한다. 하나도 없으면 링크가 없는 것이다.
- **이름·버전 불일치**: 프로젝트 설정, 검사 코드, 문서, 스토어 등록명이 서로 다른지.
- **대상 기기**: iPad가 포함되어 있는데 iPad 레이아웃을 검증한 적이 없는지.
- **구매 복원 버튼, 보호자 확인**: 있는지와 결제·복원·외부 링크 앞에 걸려 있는지.
- **다른 스토어 이름**: `scripts/scan_wording.py`로 찾는다.

## 3. 빌드 파일이 있으면 직접 본다

```
python scripts/inspect_build.py <파일.ipa 또는 .aab>
```

IPA에서 보는 것: 표시 이름, 번들 ID, 버전, 대상 기기, 사용 권한 설명 문구, 추적 허용 요청 문구가 있는지, 수출 규정 키, 광고 앱 ID, 개인정보 매니페스트별 수집 유형, 실행 파일에 들어 있는 서버 주소.
AAB에서 보는 것: 패키지명, 버전, 권한 목록(광고 ID 권한 포함), 결제 모듈.

빌드에 없는 것은 "앱이 하지 않는다"의 근거가 되고, 있는 것은 신고해야 할 것의 목록이 된다. 빌드가 없으면 "빌드로는 확인하지 못함"이라고 쓴다.

## 4. 숨은 전송 찾기

SDK 목록만으로는 부족하다. 결제 라이브러리나 엔진 서비스 패키지가 자체 통계를 보내는 일이 있고, 그 패키지의 개인정보 선언에는 빠져 있기도 하다.

1. 패키지 캐시(Unity는 `Library/PackageCache/`)에서 `UnityWebRequest`, `HttpClient`, `insights`, `telemetry`, `analytics`, `https://`를 검색한다.
2. 전송 코드가 있으면 무엇을 붙여 보내는지(설치 ID, 기기 ID, 기기 정보, 구매 정보)와 끄는 스위치가 있는지 읽는다.
3. 코드를 읽어 확인한 것인지, 실기기에서 전송을 잡아 본 것인지 구분해 적는다.

이 결과는 방침, 스토어 개인정보 신고, 체크리스트에 모두 반영한다.

## 5. 결과 정리

첫 문장에 결론을 쓰고 표 세 개로 나눈다.

1. **프로젝트에서 고칠 것**: 우선순위(필수/권장/선택), 항목, 현재 상태(근거 파일), 할 일.
2. **콘솔에서 사용자가 챙길 것**: 저장소에서 볼 수 없는 항목.
3. **법적으로 확인할 것**: 단정하지 않고 확인 대상으로 적는다.

이미 갖춰진 것도 한 단락으로 알린다. 사용자가 다시 걱정하지 않게 하기 위해서다.
