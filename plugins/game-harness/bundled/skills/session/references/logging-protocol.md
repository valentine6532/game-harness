# 작업 로그 규약

루트 `logs/YYYY-MM-DD.md`를 날짜별 append-only 작업 장부로 사용한다. 현재 상태 원본은 회차 `progress.md`, `works/{work}/EPISODES.md`, 실제 산출물과 Git이다.

## 기록 시점

다음 중 하나가 생길 때 기록한다.

- 공정 또는 의미 있는 하위 작업 완료
- 작업 중단, 외부 의존성 실패, 사용자 결정 대기
- 범위·명칭·파일 구조·품질 기준에 영향을 주는 결정
- 데이터 손실, 미추적 대용량 파일, 문서/실체 불일치 같은 위험 발견
- 다른 세션이나 사람에게 넘기는 handoff

사소한 열람, 탐색 명령, 중간 생각, 반복 테스트 성공은 기록하지 않는다.

## 항목 형식

```markdown
## HH:MM — {짧은 사건명}

- 범위: `{work}/{episode}` 또는 `project`
- 상태: `OK` | `RUN` | `STOP` | `WARN`
- 한 일: {무엇이 바뀌었는지}
- 근거: `{파일}` 또는 `{commit}` 또는 `{검증 명령과 결과}`
- 결정/주의: {없으면 `없음`}
- 다음: {재개 시 첫 행동}
```

같은 사건의 상태가 바뀌면 이전 항목을 수정하지 말고 새 시각의 후속 항목을 추가한다. 비밀, 토큰, 사용자 홈 절대경로는 기록하지 않는다.

## 진행 문서 갱신

프로젝트가 회차별 `progress.md`를 사용하면 실제 공정 상태가 바뀐 같은 세션에서 함께 갱신한다. 권장 위치는 `_workspace/{work}/{episode}/progress.md`다. clone 후에도 남아야 하는 상태는 `works/{work}/EPISODES.md`에도 반영한다.
